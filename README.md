# Mediji objav

Končne slike in videi potrjenih objav (Boško, HIVE, Superbrands) za GHL Social Planner.
GHL jih pobere prek javne povezave `https://raw.githubusercontent.com/boskoprastalo-source/bosko-objave-mediji/main/<pot>`.

Sem gre samo, kar je potrjeno in gre javno na omrežja. Nikoli: surovi posnetki, ključi, kontakti, finance, rokopis.
Pot: `<projekt>/<YYYY-MM-DD>_<oznaka>.<ext>`, največ 100 MB na datoteko.
